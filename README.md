## 📝 Project Overview
The **Library Database Management System** is designed to manage the operations of a library efficiently. It includes functionalities such as book management, member registration, book borrowing, reservations, and tracking financial fines.

## 🎯 Features
- **Book Management** 📖: Store details of books, including title, author, genre, and availability.
- **Member Management** 👥: Keep records of library members, including registration details and membership types.
- **Borrowing System** 🔄: Track which members borrow which books, along with due dates and return tracking.
- **Reservations** 🛑: Allow members to reserve books in advance.
- **Fines Management** 💰: Track financial fines for overdue book returns.
- **Library Staff Management** 🏢: Manage staff responsible for library operations.

## 🛠 Database Schema
The project follows a **relational database structure** with the following tables:
1. **Books** 📚: Stores book details.
2. **Members** 🧑‍🤝‍🧑: Contains information about library members.
3. **LibraryStaff** 🏢: Holds data about library employees.
4. **Categories** 🏷: Groups books into categories.
5. **Reservations** 🔖: Manages book reservations.
6. **FinancialFines** 💵: Tracks member fines.
7. **MemberBook** 🔄: Manages book borrowings and returns.
